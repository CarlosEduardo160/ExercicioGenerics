# Exercício Generics

Exercício sobre generics em java, criei uma classe service genérica que deve servir para atender igualmente aos métodos de alugel e devolução de veículos (carro, moto e barco) de acordo com o tipo passado nos paramêtros.

Além dos métodos atenderem de forma genérica, fiz um método wildcard que lista todos os objetos de uma lista, também funciona com base no tipo fornecido no paramêtro.
